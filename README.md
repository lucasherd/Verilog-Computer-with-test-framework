Started in Summer 2026, I made this project to begin learning computer architecture and FPGA design.
I made a working CPU with my own custom instruction set and full test framework using simulation and python scripts.
I implemented my CPU on the Basys3 FPGA board with the ability to monitor registers, RAM, program counter, and more using a multiplxed seven segment display.
I learned Verilog through a mix of YouTube tutorials, HDLbits website, and ChatGPT guidance.
I worked using visual studio code, and Pycharm, using Icarus Verilog and the Verible linter.
I used Vivado to implement my design onto the Basys3.

This is an ongoing project that I will continue to improve.
